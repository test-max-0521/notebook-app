# 📒 Notebook

A clean, minimal note-taking web app. Notes are saved to your browser's local storage.

## Features

- Create, edit, and delete notes
- Search/filter notes
- Auto-saves as you type
- Markdown editor with write/preview modes
- Slash commands (`/todo`, `/code`, `/image`, `/audio`, `/h2`)
- Templates for meeting notes, daily journal, and task lists
- Markdown support for checklists, code blocks, images, and audio embeds (`[audio](https://...)`)
- Responsive design (mobile-friendly)
- Keyboard shortcut: `Ctrl/Cmd + N` to create a new note

## Usage

Open `index.html` in your browser — no build step or server required.
